main может не дождаться завершения работы горутины
```go
func main() {
	go func() {
		fmt.Println("hello")
	}()
}
```
вывод консоли пустой, так как main завершился слишком быстро и уничтожил все запоздавшие горутины

```go
func main() {
	var wg sync.WaitGroup

	wg.Add(1)

	go func() {
		defer wg.Done()
		fmt.Println("hello")
	}()

	wg.Wait()
}
```
WaitGroup - способ дождаться выполнения горутины. 
WaitGroup после создания имеет счетчик 0
Add(1) - указывает,  что нужно ждать 0 +1 горутины
Done() - отнимает от значения счетчика 1
Wait() - блокирует переход к следующим действиям, пока счетчик != 0

В итоге так мы точно дождемся выполнения горутины, так как Wait не даст завершить программу до обнуления счетчика. Что-то типо await в JS
