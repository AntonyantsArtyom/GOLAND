каналы - способ общения между горутинами
```go
func main() {
	ch := make(chan string)

	go func() {
		ch <- "hello"
	}()

	message := <-ch

	fmt.Println(message)
}
```

message := <-ch останавливает выполнение программы до появления данных

ch <- "hello" кладет значение в канал

аналог await по своему назначению - "останови программу пока конкурентная функция не внесет значение в канал и ты его не прочтешь"
```js
const result = await calculate();
```
