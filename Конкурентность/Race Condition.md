```go
counter := 0

for i := 0; i < 1000; i++ {
	go func() {
		counter++
	}()
}
```
код выше запускает операцию ++ 1000 раз через горутины. Ожидаемое значение в counter - это 0 + 1000 = 1000. Но действительный вывод плавает и через раз становится 996 998 и так далее, результат не постоянет.

Дело в том, что ++ означает: прочитать значение переменной, прибавить 1, сохранить. Если горутины запустились на 3 разных потоках и запросили значение переменной в одно время, то каждая горутина получит значение, например, 5 - а значит сохранит 5+1. В итоге 3 запуска counter++ превратят число 5 в 6, вместо 5+3. Или какая-то медленная горутина перезапишет 5 на 3, так как она все это время обрабатывалась

Это **data race** - гонка данных, поведение ломается
