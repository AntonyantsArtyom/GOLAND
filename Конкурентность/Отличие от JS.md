в JS можно делать так:
```js
await Promise.all([
  getUser(),
  getPosts(),
]);
```
это асинхронность - на 1 потоке CPU во время ожидания 1 promise, запускается другой, по время его ожидания - обрабатывается полученный результат первого.

В GO аналогичный код выглядит так:
```go
go getUser()
go getPosts()
```
Отличие от JS в том, что если есть возможность - каждая функция сможет запуститься параллельно, если возможности нет - то механизм действия будет как и в JS. Из-за того что код может работать на разных потоках возникает проблема совместного использования памяти

 В JS - конкурентность через асинхронность, в GO - через параллелизм + асинхронность
